# Data

The training data is not stored in this repository.

Source: Kaggle, [Churn Modelling](https://www.kaggle.com/datasets/shrutimechlearn/churn-modelling)
(`shrutimechlearn/churn-modelling`), 10,000 bank customers with a binary churn target (20.4% positive,
no missing values). The Kaggle page credits [SuperDataScience](https://www.superdatascience.com/pages/deep-learning).

Licence: **unknown**. Kaggle lists the licence of this dataset as "unknown" (checked on 2026-10-15 with
`kaggle datasets metadata shrutimechlearn/churn-modelling`), so I do not redistribute the file.
The MIT licence of the code does not cover the data.

## Get the data

```bash
pip install kaggle          # and put your API token in ~/.kaggle/kaggle.json
scripts/download_data.sh    # writes data/churn.csv (git-ignored)
```

The script drops `RowNumber` and renames the columns to the names `train.py` expects
(`Exited` becomes `Churn`, `NumOfProducts` becomes `Num Of Products`, and so on).
`CustomerId` and `Surname` are not used by the model.

## Synthetic fixture

`tests/fixtures/churn_sample.csv` has 200 random rows with the same columns, generated by
`scripts/make_fixture.py` (`random_state=42`). It is made-up data with a weak signal and is only meant
for tests, CI and the Docker smoke build. Metrics in the README come from the full dataset, not from the fixture.
